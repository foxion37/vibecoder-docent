# 0039 — 터미널은 입력창의 기호로 명령과 선택 목록을 연다

Date: 2026-10-07
Status: Accepted. 사용자 요청. ADR 0038의 선택 방법에 입력창 메뉴를 더한다. Ctrl 단축키는 유지한다.

## Context

ADR 0038의 터미널은 세션, 대화, 답변, 프로필을 Ctrl 단축키로만 골랐다. 사용자는 단축키를 외우기보다 OMP처럼 입력창에 `/`, `@` 같은 기호를 쳐서 목록에서 직접 고르기를 원했다. 설명 깊이와 모델 같은 설정은 웹앱에서만 바꿀 수 있었다.

## Decision

1. 입력창 전체가 기호 하나와 거르기 글자로만 이루어져 있으면 입력창 바로 아래에 선택 목록을 띄운다. 기호는 네 가지다.
   - `/` 명령: 세션, 대화, 답변, 설정, 새로고침, 종료. 설명이 진행 중이면 바로잡기와 중단도 나온다. 세션, 대화, 설정 명령은 해당 기호의 목록으로 이어진다.
   - `@` 세션: 세션 제목, 작업 폴더, 제공자로 거른다.
   - `#` 대화: 세션 전체 대화, 사건 카드, 저장된 대화.
   - `$` 설정: 현재 프로필의 기본 설명 깊이(EASY, NORMAL, HARD), 미리 설명 켜기와 끄기, 설명 모델(omp 카탈로그), 프로필 바꾸기.
2. 기호 뒤에 쓴 글자는 공백으로 나눈 낱말이 모두 들어간 항목만 남긴다. 위아래 방향키로 고르고 Enter나 Tab으로 실행하며, 지금 쓰고 있는 항목에는 체크 표시를 둔다. 목록은 Pi의 선택 목록처럼 `→`와 강조색으로 현재 항목을 표시한다.
3. 실행한 기호 글자는 질문으로 보내지 않고 입력창에서 지운다. 일치하는 항목이 없으면 Enter를 눌러도 보내지 않고 안내만 한다. Esc를 누르면 목록을 닫고 그 글자를 일반 질문 글자로 남긴다. 기호로 시작하는 질문도 이렇게 보낼 수 있다.
4. 설정은 기존 프로필 API(`PATCH /api/profiles/:id`)로 바꾼다. 모델은 ADR 0016처럼 카탈로그의 정확한 selector만 저장하며, 서버가 거부하면 바꾸지 않고 오류를 보여 준다. 프로필 만들기와 분야별 설명 깊이는 웹앱 설정에 남긴다.
5. 바로잡기 입력 중에는 기호 목록을 띄우지 않는다. 바로잡기 문장은 그대로 보낸다.

## Consequences

- 단축키를 몰라도 `/` 하나로 모든 기능을 찾을 수 있다. Ctrl 단축키는 익숙한 사람을 위해 남긴다.
- `$`, `#`, `@`, `/`로 시작하는 질문은 Esc를 한 번 더 눌러야 보낼 수 있다.
- 메뉴 선택은 모델을 호출하지 않는다. `$`를 처음 열 때 모델 목록을 한 번 불러온다.
