# 0038 — 터미널은 입력창을 고정하고 단축키로 대화와 답을 고른다

Date: 2026-10-07
Status: Accepted. 사용자 요청. ADR 0037의 터미널 화면 조작을 구체화한다.

## Context

사용자는 Herdr의 분할 창에서 도슨트를 사용하며, OMP처럼 컬러 테마와 항상 보이는 Composer, Status Line을 요청했다. 기존 터미널은 목록과 입력 화면을 오가며 `i`, `q`, `!` 같은 한 글자를 명령으로 사용했다. 대화를 고르거나 이전 답을 읽을 때 질문 입력 흐름이 끊겼다. 첫 구현은 색만 비슷했고 OMP 테마의 HTML 내보내기용 배경색을 화면 전체에 칠했으며 Markdown을 일반 글자로 보여 줘, 사용자가 "Pi 스타일로, OMP 디자인을 제대로 참고하라"고 다시 요청했다.

## Decision

1. 화면 구조는 Pi 대화형 모드를 따른다. 위에서부터 제목과 단축키, 대화, 진행 표시(설명 중에만), 전체 너비 가로선 위아래의 입력창, 두 줄 상태줄이다. 입력창에는 테두리 모서리나 옆선, 제목 라벨을 두지 않는다. 내용이 넘치면 위 가로선에 숨은 줄 수를 표시하고 커서를 따라간다.
2. 메시지는 Pi와 OMP의 배치를 따른다. 질문은 위아래 한 줄 여백이 있는 파란 배경 블록, 설명은 배경 없는 Markdown(좌우 한 칸), 카드의 AI 원문은 금색 라벨이 붙은 회색 배경 블록이다. Markdown은 Pi의 실제 렌더러(`@earendil-works/pi-tui`)로 그린다. 제목, 목록, 표, 인용, 코드 블록의 구조를 유지하며 별도 파서를 만들지 않는다.
3. 색상은 사용자의 OMP `titanium-prompt-focus` 테마의 역할 값을 그대로 쓴다. 본문은 터미널 기본 색을 상속하고, 테마의 `export` 배경색(HTML 전용)은 쓰지 않는다. 강조와 제목은 `#00b4ff`, 질문은 흰 글자에 `#243B53`, 인라인 코드는 `#00ff88`, 코드 블록과 보조 글자는 `#9ca3b0`, 가로선과 원문 블록은 `#2a3038`, 상태줄의 경로와 모델은 `statusLinePath`와 `statusLineModel` 값이다. 선택 목록의 현재 항목은 배경을 칠하지 않고 `→`와 강조색 글자로 표시한다. 입력창 가로선은 질문일 때 강조색, 바로잡기일 때 경고색, 목록을 여는 동안 흐린 색이다. 터미널 기능에 따라 RGB, 256색, 기본 ANSI를 사용하며 `NO_COLOR`와 `TERM=dumb`에서는 색을 쓰지 않는다. OMP 개인 설정 파일을 실행 중 읽거나 변경하지 않는다.
4. 원문과 설명은 렌더링 전에 제어 문자를 제거한다. 렌더러가 만든 색 코드만 남기며, 내용에서 온 커서 이동, 화면 지우기, 클립보드와 하이퍼링크(OSC) 코드는 출력하지 않는다.
5. Ctrl+P는 세션, Ctrl+T는 대화, Ctrl+O는 현재 대화의 저장된 답변, Ctrl+G는 프로필 선택이다. 목록에서는 방향키와 Enter로 고르고 Esc로 입력창에 돌아온다. 대화 목록에는 세션 전체 대화, 사건 카드, 카드가 최근 목록에 없어도 저장된 스레드가 들어간다.
6. 답변 선택은 같은 스레드에서 읽는 위치만 바꾼다. 원래 질문과 답을 함께 보여 주고, 모델 호출이나 새 스레드를 만들지 않는다. 세션 전체 대화의 답변 목록에도 그 스레드의 문답만 표시한다.
7. 일반 글자는 모두 질문 입력이다. Enter로 보내고 Ctrl+J로 줄을 바꾼다. Ctrl+S로 바로잡기 입력을 전환하고, Ctrl+C는 설명 중단, Ctrl+R은 새로고침 또는 끊긴 요청 재연결, Ctrl+D는 클라이언트 종료다. 이미 연결된 요청에 Ctrl+R을 눌러 중복 스트림을 만들지 않는다.
8. 초안과 커서는 프로필, 세션, 스레드, 질문 또는 바로잡기별로 메모리에 보관한다. 목록을 닫거나 다른 대화로 갔다 돌아와도 유지한다. 중단한 질문은 해당 입력창이 비어 있을 때 돌려주며, 사용자가 이미 작성한 새 초안은 덮어쓰지 않는다. 클라이언트 종료 후 초안 복원은 제공하지 않는다.
9. 진행 상태, 오류, 중단 안내는 Pi처럼 입력창 바로 위 한 줄에 둔다. 상태줄에는 작업 폴더, 세션, 프로필, 설명 깊이, 현재 대화, 문답 수, 스크롤 위치, 선택한 모델만 보여 준다. 토큰이나 비용처럼 서버가 제공하지 않는 수치를 꾸며 표시하지 않는다.

## Consequences

- 질문을 입력하다가 대화나 답을 확인한 뒤 같은 초안으로 돌아올 수 있다.
- 기존 한 글자 조작은 제거한다. 사용법과 CLI 도움말도 새 단축키로 바꾼다.
- 터미널 클라이언트만 변경한다. 기존 설명 API, 저장소, 웹앱, 모델 선택과 서버 수명은 유지한다.
- 설치 패키지에 첫 런타임 의존성 `@earendil-works/pi-tui`가 생기고 Node 최소 버전이 22.19로 오른다. 웹앱과 서버는 이 의존성을 쓰지 않는다.
- OMP 기본 입력창 모양인 powerline 띠(`band`)가 아니라 OMP에도 있는 Pi 모양(`pi`)을 택했다. 사용자가 Pi 스타일을 요청했기 때문이다.
- 검증은 실제 Herdr 화면의 ANSI 출력과 raw TTY 입력, HTTP 스트림으로 한다. 웹 CSS용 디자인 검사 결과로 터미널 화면을 검증했다고 주장하지 않는다.
