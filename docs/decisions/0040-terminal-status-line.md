# 0040 — 터미널 상태줄은 OMP처럼 항목별 아이콘과 색으로 보여 준다

Date: 2026-10-07
Status: Accepted. 사용자 요청. ADR 0038 §9의 상태줄 내용을 넓힌다.

## Context

ADR 0038의 상태줄은 작업 폴더, 세션, 프로필, 설명 깊이, 대화, 문답 수, 모델을 흐린 글자로 나열했다. 사용자는 OMP 상태줄처럼 항목마다 아이콘과 색을 달고, 모델 추론 수준, 즐겨찾기 수, 저장된 대화 수, 학습 시간도 보여 주기를 원했다. 규칙을 먼저 만들고 그에 맞춰 고치라고 했다.

## Decision

1. 상태줄의 항목, 아이콘, 색, 우선순위, 시간 표기는 `docs/terminal-status-line.md`가 정본이다. 코드의 `STATUS_RULES`와 `STATUS_ICONS`는 이 표를 그대로 옮긴다.
2. 아이콘과 색은 OMP 기본 `unicode` 기호 세트와 사용자의 `titanium-prompt-focus` 테마 토큰을 따른다. OMP에 없는 항목(설명 깊이, 문답, 프로필)만 도슨트 아이콘을 정한다.
3. 추론 수준은 서버가 설명 깊이에서 정하는 thinking 수준을 보여 준다. 이 표는 서버와 터미널이 함께 쓰도록 `app/depth.mjs`로 옮긴다.
4. 학습 시간은 이 세션에서 직접 물어본 문답의 설명 시간 합계다. 미리 설명은 사용자가 요청하지 않았으므로 빼고, 측정값이 없는 옛 기록은 더하지 않는다. 화면을 열어 둔 시간이나 읽은 시간은 측정하지 않는다.
5. 즐겨찾기 수는 기존 `GET /api/favorites`에서 읽는다. 세션을 열 때와 대화 기록을 다시 불러올 때 함께 갱신한다.
6. 화면이 좁으면 우선순위가 낮은 항목부터 통째로 뺀다. 토큰, 비용처럼 서버가 주지 않는 수치는 표시하지 않는다.

## Consequences

- 상태줄만 보고 지금 어떤 모델과 깊이로 설명받는지, 이 세션에서 얼마나 물었는지 알 수 있다.
- 이모지 아이콘은 터미널 글꼴에 따라 폭이 다를 수 있다. 폭 계산은 Pi 렌더러의 `visibleWidth`를 쓴다. `TERM=dumb`이나 `DOCENT_SYMBOLS=ascii`에서는 ASCII 아이콘으로 바꾼다.
- 학습 시간은 "설명을 만드는 데 걸린 시간"이라 실제 공부 시간과 다를 수 있다. 문서와 규칙 표에 정의를 적어 둔다.
